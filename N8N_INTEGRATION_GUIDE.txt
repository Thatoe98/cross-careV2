===============================================================================
STEP 1: SET UP N8N WORKFLOW
===============================================================================

1.1 Access Your N8N Instance:
   - Go to: https://n8n-service-zmzi.onrender.com
   - Log into your n8n dashboard

1.2 Create New Workflow:
   - Click "New Workflow"
   - Name it: "Cross-Care Chatbot API"

1.3 Add Webhook Node (Trigger):
   - Drag "Webhook" node from the trigger section
   - Configure:
     * HTTP Method: POST
     * Path: /chatbot
     * Response Mode: "Respond to Webhook"
   - Save and activate the webhook
   - Copy the webhook URL (it will look like: https://n8n-service-zmzi.onrender.com/webhook/[unique-id])

===============================================================================
STEP 2: CONFIGURE AI PROCESSING IN N8N
===============================================================================

2.1 Add AI Node (Choose one option):

OPTION A - OpenAI ChatGPT:
   - Add "OpenAI" node
   - Configure:
     * Resource: Chat
     * Model: gpt-3.5-turbo or gpt-4
     * Messages: {{ $json.message }}
     * System Message: "You are a helpful medical assistant for Cross-Care Medical Services. Provide information about medical referrals between Myanmar and Thailand, hospital partnerships, and general healthcare guidance. Keep responses concise and professional."

OPTION B - Other AI Services:
   - Use HTTP Request node to call other AI APIs
   - Configure headers and authentication as needed

2.2 Add Data Processing Node:
   - Add "Code" node after AI node
   - Add JavaScript code to format the response:
     ```
     return [{
       json: {
         response: $input.first().json.choices[0].message.content,
         timestamp: new Date().toISOString(),
         user_message: $node["Webhook"].json.message
       }
     }];
     ```

STEP 3: UPDATE CHATBOT CODE FOR N8N INTEGRATION
===============================================================================

✅ ALREADY IMPLEMENTED: Basic chatbot structure with async support

3.1 Replace the getBotResponse() function in js/chatbot.js:
   - The function is already async-ready
   - Replace the current logic with your n8n webhook URL
   
3.2 Update getBotResponse() with your N8N webhook:
   ```javascript
   async function getBotResponse(userMessage) {
       try {
           const response = await fetch('YOUR_N8N_WEBHOOK_URL_HERE', {
               method: 'POST',
               headers: {
                   'Content-Type': 'application/json',
               },
               body: JSON.stringify({
                   message: userMessage,
                   timestamp: new Date().toISOString()
               })
           });
           
           if (response.ok) {
               const data = await response.json();
               return data.response || "I'm sorry, I couldn't process that request.";
           } else {
               return "I'm experiencing technical difficulties. Please try again later.";
           }
       } catch (error) {
           console.error('Error calling chatbot API:', error);
           return "I'm currently unavailable. Please use our contact form for assistance.";
       }
   }
   ```

SAMPLE N8N WORKFLOW STRUCTURE
===============================================================================

1. Webhook (Trigger)
   ↓
2. Code Node (Input Validation)
   ↓
3. OpenAI Node (AI Processing)
   ↓
4. Code Node (Response Formatting)
   ↓
5. Respond to Webhook (Return Response)

Alternative with Database:
1. Webhook → 2. Database (Store Message) → 3. AI Processing → 4. Database (Store Response) → 5. Return Response

===============================================================================
TROUBLESHOOTING TIPS
===============================================================================

Common Issues:
- CORS errors: Check your domain whitelist in n8n
- Slow responses: Add timeout handling in frontend
- API failures: Implement fallback responses
- Rate limiting: Add usage tracking

Testing Commands:
- Use browser dev tools to monitor network requests
- Test webhook directly with Postman or curl
- Check n8n execution logs for errors

===============================================================================
SECURITY CONSIDERATIONS
===============================================================================

1. API Key Management:
   - Store OpenAI/other API keys securely in n8n
   - Never expose keys in frontend code

2. Input Validation:
   - Sanitize user inputs in n8n workflow
   - Prevent injection attacks

3. Rate Limiting:
   - Implement per-user rate limits
   - Monitor for abuse patterns

4. HTTPS Only:
   - Ensure all API calls use HTTPS
   - Validate SSL certificates
