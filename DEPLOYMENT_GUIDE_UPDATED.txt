DEPLOYMENT STEPS
===============================================================================

STEP 1: SET UP VERCEL ENVIRONMENT VARIABLE
------------------------------------------
⚠️ IMPORTANT: You must add your OpenAI API key to Vercel!

1. Go to your Vercel dashboard (vercel.com)
2. Select your cross-care project
3. Go to Settings → Environment Variables
4. Add new variable:
   Name: OPENAI_API_KEY
   Value: [Paste your OpenAI API key here]
   Environment: Production, Preview, Development

STEP 2: DEPLOY TO VERCEL
------------------------
Your files are ready! Push to your repository:

git push origin main

Vercel will automatically deploy your changes.

===============================================================================
TROUBLESHOOTING
===============================================================================

❌ IF CHATBOT DOESN'T RESPOND TO TEAM QUESTIONS:
1. Check if data/company-knowledge.json deployed properly
2. Verify the team section is included in knowledge base
3. Check Vercel function logs for errors

❌ IF MEDICAL RESPONSES ARE GENERIC:
1. Ensure medical_response_guidelines are in knowledge base
2. Check system prompt includes medical handling instructions
3. Verify OpenAI API is receiving full context

❌ IF API KEY ERRORS:
1. Verify OPENAI_API_KEY is set in Vercel environment variables
2. Check API key is valid and has credits
3. Ensure environment variable name matches exactly
